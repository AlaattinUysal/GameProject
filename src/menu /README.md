# Game Menu

## Proje Yapısı

```
game-menu/
├── menu/
│   ├── init.py         # Makes the menu directory a Python package

│   ├── ui.py           # UI-related classes (PixelButton, Slider, etc.)
│   ├── menu_logic.py   # Main Menu class and its logic
│   └── main.py         # Entry point to run the menu

├── README.md
└── LICENSE
```
