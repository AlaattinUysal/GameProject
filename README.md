Bölüm tasarımları tiled programı kullanılarak yapılmıştır. Tiled görselleştirmede, animasyonların ayarlanmasında ve collision alanlarının koyulmasında kolaylık sağlar.
Kullanılan assetler çeşitli sanatçılar tarafından çizilip craftpix.net ve itch.io sitelerinde paylaşılmıştır. Tamamı satın alınmış ya da CC0 lisanslıdırlar.
".tmx" uzantılı olarak kaydedilen bölümler pytmx kütüphanesi ile okunur ve ekrana çizilir. kütüphaneyi indirmek için =>  pip install pytmx
